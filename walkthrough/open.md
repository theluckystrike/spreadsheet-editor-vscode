# Open a file

- Excel (.xlsx, .xlsm): click the file. It opens in Spreadsheet Editor.
- CSV and TSV: click the table icon in the editor title, or right-click the file and pick Open in Spreadsheet Editor.
- To open every CSV and TSV here, run Spreadsheet Editor: Make Spreadsheet Editor the Default for CSV and TSV. Open as Text in the editor title switches back for one file.

Delimiter, quote character, encoding, comment lines and the header row are detected. You can change each one in the toolbar.
