# Find, replace and filter

- Ctrl+F (Cmd+F on a Mac) opens find and replace. Turn on match case, regular expressions or whole cell.
- Replace All changes every match in the rows shown, or only in the selection. One Ctrl+Z takes it back.
- The Filter rows box shows rows that contain some text. The SQL box takes a condition such as `price > 10 AND city LIKE 'Par%'`.
- Sorting and filtering change the view only. The file keeps its row order.
